# CrimeaVox — сайт

React + Vite. Розділи: головна, Новини, Події, Блоги, Про нас, окрема сторінка для кожного матеріалу.

## Запуск

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm run build    # готовий сайт у папці dist/
```

Папку `dist/` можна залити на будь-який хостинг (Netlify, Vercel, GitHub Pages, звичайний хостинг) — серверне налаштування не потрібне.

## Як додати новину, подію чи колонку

Увесь контент лежить у `src/data.js`. Скопіюйте наявний об'єкт у масив `news`, `events` або `blogs` і змініть поля.

- `slug` — адреса сторінки латиницею, унікальна.
- `date` — у форматі `РРРР-ММ-ДД`. Події з датою в минулому самі переїжджають у «Минулі».
- `img` — шлях до фото, наприклад `/img/obmin.jpg` (покладіть файл у `public/img/`). Без фото показується кольорова заглушка `tone` (a–f).
- `title` + `accent` — заголовок; `accent` виділяється червоною плашкою.
- `body` — масив абзаців тексту.

## Структура

```
src/
  data.js              контент
  styles.css           стилі
  main.jsx             маршрути
  components/Layout.jsx  шапка, підвал, підписка
  components/Cards.jsx   картки новин, подій, блогів
  pages/Home.jsx         головна
  pages/Lists.jsx        списки розділів
  pages/Detail.jsx       сторінки матеріалів
  pages/About.jsx        про нас
```

## Що зробити перед запуском

- Замінити тексти-заглушки та імена авторів у `src/data.js` на справжні.
- Додати фото.
- Підключити форму підписки до сервісу розсилок (`components/Layout.jsx`).
- Вставити посилання на Telegram, YouTube, контакти.
- Оновити цифру політв'язнів на головній.
- Коли контенту стане багато — перенести `data.js` у CMS (Sanity, Strapi, WordPress) і зробити адмінку для редакції.
